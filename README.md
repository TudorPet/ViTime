# Timetable Generator

A small web app that reads a school timetable exported as a PDF (one class per
page, generated by aSc Timetables) and shows the schedule of each teacher.

Upload the PDF, pick a teacher from the list, and see every lesson they teach:
day, period, class, subject, room and group.

## Requirements

- Python 3.13
- Packages `streamlit` and `pymupdf`

## Installation

```powershell
py -3.13 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Always install packages with `python -m pip ...` while the virtual environment
is active, so they go into the right Python.

## Running the app

Double-click `start.bat`, or run:

```powershell
.venv\Scripts\activate
streamlit run app.py
```

Your browser opens the app. To stop it, press `Ctrl+C` in the terminal.

## Project structure

| File | Purpose |
| --- | --- |
| `app.py` | The Streamlit web page (upload, teacher picker, schedule table). |
| `orar_teachers.py` | Reads lessons from a page: subject, teacher, room, group, class name. Builds the per-teacher schedules. |
| `orar_merged_cells.py` | Finds the table grid and detects merged cells (lessons spanning several periods). |
| `start.bat` | Launcher for Windows. |

## How it works

- The timetable grid is rebuilt from the vertical and horizontal lines drawn in
  the PDF. Where a vertical separator is missing, the periods are merged, so
  the lesson is counted for every period it covers.
- Text is read character by character and grouped into chunks. Large text is
  the subject. Small text on the right of a cell is the teacher, and small text
  on the left is the room.
- A lesson with no room in its cell uses the class's default room, printed
  above the table on the right.
- Groups inside one cell are separated by the thin horizontal line drawn
  between them.
- The class name is read from the large title at the top of each page.

## Assumptions and limitations

- Every page uses the same layout as the aSc Timetables export (same grid
  position, 5 days, 13 periods).
- Teachers appear as the short codes printed in the timetable (for example
  `JoDo`). The PDF does not contain full names.
- Subject text is expected to be in a font size of at least 10 pt, and
  teacher, room and group text smaller than that.
- Each page is expected to hold exactly one class timetable. A page where no
  lessons are found produces a warning.

## Privacy

Timetables contain teachers' names and schedules. Do not commit the PDFs to a
public repository (`*.pdf` is best kept in `.gitignore`).
